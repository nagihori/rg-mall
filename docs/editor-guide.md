# 更新担当者向け：イベント告知の作り方

## 公開までの4手順

1. **新しいイベント** を選びます。
2. タイトル、短い説明、本文、開催期間を上から順に入力します。
3. 写真を追加する場合は、写真を選び「この写真に何が写っているか」と権利メモを入力します。
4. **プレビュー** で表示を確認し、問題がなければ **確認を依頼** を選びます。確認者が公開します。

## 入力のコツ

- タイトルはイベント名をそのまま書きます。例: `秋の収穫祭 2026`
- 短い説明は、一覧で最初に見える紹介文です。誰が、何を、いつできるかを一文で書きます。
- 本文は「概要」「開催期間」「参加方法」「注意事項」の順にすると読みやすくなります。
- 日時は本文だけで済ませず、必ず日時欄にも入力します。サイトが自動で「開催中」「開催予定」を判断します。
- 写真に人物や重要なゲーム内要素が写る場合は、内容が伝わる説明を入れます。

## しないこと

- 公開済みの記事を削除しないでください。誤りがあれば確認者へ連絡し、非公開または修正を依頼します。
- HTML、画像リンク、コピー元が不明な写真を本文へ貼り付けないでください。
- 開始前に「開催中」と書かないでください。表示は日時欄から自動で決まります。

## 困ったとき

- 保存できない: 赤く表示された入力欄を確認し、直してからもう一度保存します。
- 写真を追加できない: ファイル形式とサイズを確認し、権利メモを入力します。
- 急いで修正したい: 既存記事を編集して保存し、確認者に「緊急修正」と連絡します。公開画面には、再公開されるまで前の内容が残ります。
