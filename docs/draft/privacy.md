# rg-mall プライバシーポリシー

最終更新日：2026年8月29日

rg-mall（以下「本サービス」）では、サービスの提供および管理のため、必要な範囲で利用者の情報を取り扱います。

## 1. 取得する情報

本サービスでは、Discord OAuthによるログイン時に、Discordから提供される以下の情報を取得する場合があります。

- DiscordユーザーID
- Discordユーザー名
- Discordアバター等の公開プロフィール情報

本サービスでは、ログインおよび利用者の識別に必要な範囲でこれらの情報を利用します。

## 2. 利用目的

取得した情報は、主に以下の目的で利用します。

- 管理画面へのログイン認証
- 利用者の識別および権限管理
- 本サービスの運営およびセキュリティ確保

## 3. 第三者への提供

取得した個人情報を、法令に基づく場合を除き、本人の同意なく第三者へ提供することはありません。

## 4. 情報の管理

取得した情報について、適切な安全管理措置を講じ、不正アクセスや漏えい等の防止に努めます。

## 5. 外部サービス

本サービスでは、認証のためにDiscordのOAuth機能を利用しています。

Discordによる情報の取り扱いについては、Discordのプライバシーポリシー等をご確認ください。

## 6. ポリシーの変更

必要に応じて本プライバシーポリシーを変更することがあります。変更後の内容は、本ページに掲載した時点から適用します。
